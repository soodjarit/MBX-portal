ประเภท 1 / 7
Welcome Campaign · สมาชิกใหม่

Segment Filter ตามวันที่สมัคร

  • 1เมนู Configuration → Customer Segments → New
  • 2ตั้ง Domain: Membership Joined At มากกว่าหรือเท่ากับ N วันที่แล้ว (field จริง: mbx_membership_joined_at)
  • 3กลับไปแคมเปญ → Add Targets → From Segment → เลือก segment ที่เพิ่งสร้าง
ข้อควรระวัง: ฝั่ง Reward (MXP) มีเงื่อนไขซ้อนอีกชั้น — Privilege Condition = "New Member" — ต้องตั้งจำนวนวันให้ตรงกันทั้ง 2 ฝั่ง ไม่งั้น target list จะกว้าง/แคบกว่าเงื่อนไขจริงที่ reward เช็คตอนลูกค้ากดรับ
Customer Segment — ตั้ง Domain Filter
ประเภท 2 / 7
Birthday Campaign

วันเกิดลูกค้าแต่ละคน — ระบบส่งคูปองให้เองอัตโนมัติ ไม่ต้องยิงแคมเปญราย event

  • 1Reward → tab MBX Membership → Eligibility Rule = Birthday Month (เช็คจากฟิลด์ Birth Date ของ partner จริง)
  • 2Automated Journey Rule → Trigger Type = Recurring → ผูกกับ Reward ด้านบน
  • 3Cron รายวันสแกนหาลูกค้าที่เดือนเกิดตรงกับเดือนปัจจุบัน → ออกคูปองให้อัตโนมัติ ไม่ต้องเข้าไป Add Targets เอง
รันจริงแล้ว: ตั้ง Reward "Birthday Month 10% Discount Coupon" + Rule "Birthday Month — Auto-Claim 10% Coupon" ให้ลูกค้า [DEMO-LOYAL] คุณสุดา (เดือนเกิดกรกฎาคม) → cron ยิงอัตโนมัติ → claim สถานะ Done + ออกคูปอง CDPDEMOC-A780465332 (ลด 10%, หมดอายุ 30 วัน) ให้ทันที ไม่ต้องมีคนกดอะไรเลย
Automated Journey Rule จริง — ตั้งครั้งเดียว รันทุกเดือน
ผลจริง — claim Done + คูปองออกให้อัตโนมัติ
ประเภท 3 / 7
Tier Campaign · ระดับสมาชิก

Segment Filter ตาม Pricelist Level

  • 1Domain: property_product_pricelist → mbx_level เท่ากับ level ที่ต้องการ
  • 2ระดับสมาชิกผูกอยู่กับ Pricelist ที่ partner แต่ละคนถูก assign ไว้ — เปลี่ยน level ได้จากหน้า partner โดยตรง
  • 3ใช้ทำโปรโมชั่นเฉพาะระดับ เช่น "Level 8-10 รับสิทธิ์พิเศษ"
Segment domain filter — เปลี่ยนแค่เงื่อนไขจาก type อื่น
ประเภท 4 / 7
Personalize Campaign

Select Customers Manually — ไม่มีกฎตายตัว เลือกทีละคน

  • 1Add Targets → เลือกโหมด Select Customers Manually
  • 2เลือกลูกค้าทีละคน/กลุ่มเล็กด้วยมือ — เหมาะกับแคมเปญเฉพาะกิจที่ไม่มีเงื่อนไขระบุเป็นกฎตายตัวได้ (เช่น VIP เฉพาะราย)
ตัวอย่างจริงในระบบ: "VIP Member Refer-a-Friend" — สร้างด้วยการเลือกลูกค้ามือแบบนี้ — claim rate 35.6%, usage rate 31.2% (active)
Add Targets wizard — โหมด Select Customers Manually
ประเภท 5-7 / 7
Inactive / Active / Top Spender — กลไกเดียวกันหมด

Segment สำเร็จรูป 3 แบบ — เลือกจาก Dropdown ไม่ต้องเขียน Domain เอง

i
เบื้องหลัง
ระบบมี field ใหม่บน res.partner — Last Order Date และ Purchase Status คำนวณจาก confirmed sale order อัตโนมัติทุกคืนผ่าน cron "Campaign: Refresh Customer Purchase Stats"
5. Inactive Member
Segment สำเร็จรูป "Inactive Member (No Order in 90+ Days)" — ครอบคลุมทั้งซื้อครั้งสุดท้ายเกิน 90 วัน และไม่เคยซื้อเลย
6. Active Member
Segment สำเร็จรูป "Active Member (Last Order ≤ 90 Days)" — ใช้ field/cron ชุดเดียวกับ Inactive Member
7. Top Spender
Segment สำเร็จรูป "Top Spender (Last 90 Days)" — เป็นการจัดอันดับ มี "Sort By" (mx_spend_90d desc) + "Limit" (ตั้งไว้ 50) ปรับเป็น Top 100/Top 20 แก้ที่ Limit ได้ตรงๆ
ปรับ window 90 วันได้จากซอร์สโค้ดเท่านั้น: ตัวเลข "90 วัน" เป็นค่าคงที่ในโค้ด (PURCHASE_ACTIVE_WINDOW_DAYS ใน res_partner.py) เปลี่ยนได้แต่ต้องแก้โค้ด+อัปเกรดโมดูลใหม่ ไม่ใช่ค่าที่ปรับได้จากหน้าจอ
ขั้นตอนที่ 3-4 · เหมือนกันทุกประเภท

ผูก Reward กับแคมเปญ แล้วกด Invite

  • 1Sales → Loyalty Programs → เปิด Reward → tab MBX Membership → กลุ่ม "Restrict to Campaign(s)" → เลือกแคมเปญนี้
  • 2กลับมาที่แคมเปญ → tab Targets → เลือกแถว (หรือทั้งหมด) → ปุ่ม Invite
  • 3ระบบออกคูปองให้ทันทีถ้าลูกค้าผ่านเงื่อนไข — target เปลี่ยนเป็น Responded อัตโนมัติ
Bug พบ+แก้แล้ว: loyalty.program ทุกตัว default ผูก Company เป็นบริษัทที่ user active อยู่ตอนสร้าง (ไม่มี UI เตือน) — ถ้าเผลอปล่อยไว้ โปรแกรมจะมองไม่เห็นที่ POS บริษัทอื่นเลย ต้องเคลียร์ field Company ให้ว่างเปล่า (global) เสมอทุกครั้งที่สร้าง Reward ใหม่ที่ใช้ร่วมกับ CDP-CM
